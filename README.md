# 小刘的个人技术博客

以静态主站为核心的个人技术博客。站点包含首页、文章、归档、分类标签、全文搜索、项目空间、合作服务、文章点赞与审核评论、可管理简历仓库、Redis 站点脉搏、站点管理中心、关于页、深浅主题、RSS、站点地图和移动端适配。

“合作服务”分为毕业设计项目陪跑和开发兼职合作。毕设服务只提供技术指导、项目实现陪跑、代码讲解和部署支持，不提供论文代写、数据造假、冒名提交或替代答辩。

## 本地预览

在本目录启动自带的零依赖预览服务：

```powershell
node scripts/serve.js
```

然后访问 `http://127.0.0.1:4173/`。

## 新增文章

先在简历仓库或管理中心输入管理口令，再进入“文章”页面，点击“创建文章”。填写标题、摘要、栏目、左侧分类标签和正文后即可发布；发布时间和阅读时间由系统自动生成，列表按时间从新到旧排列。正文中单独一行使用 `## 章节标题`，会自动生成本文目录。管理模式下可以删除文章；游客看不到创建和删除入口。

## 新增项目

打开 `blog-assets/data.js`，在 `BLOG_DATA.projects` 数组中复制一项。`url` 填项目登录页，`source` 填公开源码地址。不要填写账号、密码、数据库地址或其他生产配置。

## 管理简历仓库

- 部署 `resume-service/` 中的轻量服务，并通过 Nginx 将 `/blog-api/` 转发到 `127.0.0.1:8091`；
- 在简历仓库页面点击“上传新简历”，输入服务器生成的管理口令；
- 每份 PDF 独立保存，可以设为当前版或从公开区删除；
- 删除后的文件进入服务器恢复区，不继续公开；
- 上传前必须检查真实姓名、私人联系方式、家庭地址、账号凭据、内部地址及公司保密内容。

## Redis 站点脉搏

`#/pulse` 展示近 5 分钟在线人数、当天 PV、当天近似 UV 和文章热榜。Redis 使用 String、HyperLogLog、Sorted Set、TTL 与原子计数；原始 IP、聊天正文和联系方式不会写入 Redis。Redis 断开时统计模块自动降级，SQLite 中的文章、评论、合作需求和简历不受影响。

动态 API 默认使用 16 个固定工作线程和 64 个排队位置。达到容量后返回 503，不无限创建线程；这是小服务器的过载保护，不代表已经达到“一万并发”，最终容量必须以分级压测结果为准。

## 发布到 GitHub Pages

仓库创建并推送后，在 GitHub 仓库的 `Settings → Pages` 中选择：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

GitHub Pages 可以作为备用预览地址；正式站点部署在 `https://xiaoliudev.com/`，服务器发布方法见 `deploy/DEPLOY-GUIDE-ZH.md`。

## 技术说明

- 文章页面由静态前端直接渲染，管理员发布的文章正文保存在现有 SQLite 数据库中；
- Hash 路由，兼容 GitHub Pages 子目录；
- 搜索和主题切换均在浏览器本地完成；
- 博客服务主体使用 Python，简历文件使用服务器目录，发布文章、点赞、评论和合作留言使用 SQLite，高频访问统计与限流使用本机 Redis；
- 管理口令只保存在服务器环境文件和当前浏览器会话；
- 博客与康联云业务系统完全分离。
